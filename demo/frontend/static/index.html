A.X K2 데모

Azure의 A100 GPU 16장(2노드)에서 서빙하는 SK텔레콤 A.X K2 체험 페이지입니다. 공유받은 비밀번호를 입력해 주세요.

A.X K2 on Azure A100 × 16
확인 중

A.X K2에게 물어보세요

추론(Thinking) 모드를 켜면 답하기 전에 생각하는 과정을 펼쳐 볼 수 있습니다. 대화 내용은 서버에 저장되지 않고 이 브라우저 탭에만 남습니다.

클러스터 상태

실시간 지표

vLLM 지표를 5초마다 읽습니다. 생성 속도는 서버 전체에서 초당 만들어지는 토큰 수입니다.

리전별 GPU 노드

이 데모는 노드 2대가 한 리전에 함께 있어야 해서(InfiniBand 연결), 켜면 세 리전에 동시에 요청하고 먼저 2대를 확보한 리전 하나만 남깁니다. 저우선순위 VM이라 Azure가 회수할 수 있으며, 회수되면 자동으로 다시 시작합니다.

구성도

단일 노드 레퍼런스(B200/H100급)와 다른 점

벤치마크: SKT 공개값과 이 데모 비교

SKT 공개값은 Hugging Face 모델 카드의 추론(Thinking) 모드 표입니다. 이 데모 값은 같은 모델(FP8 체크포인트)을 A100 16장에서 돌려 채점한 결과이며, 문항 수·반복 횟수·채점기가 SKT와 다를 수 있어 참고용입니다. ±는 95% 신뢰구간입니다.

처리량 (동시 요청 32, 출력 1,024 토큰)

B200 값은 SKT 기술 보고서 Fig. 7·9의 막대 라벨이고, A100 값은 같은 vLLM 벤치마크 명령으로 직접 측정한 값입니다.

그래프

이 데모는

  • SK텔레콤이 공개한 A.X K2(총 688B, 활성 33B 파라미터 MoE, Apache-2.0 라이선스)를 H100 없이 Azure의 A100 GPU 16장(ND96amsr_A100_v4 2대)에서 서빙합니다.
  • SKT의 공식 서비스가 아닙니다. 기술 검증용 데모이며 응답 품질과 속도는 SKT 환경과 다를 수 있습니다.
  • 모델 가중치와 설정은 공개된 그대로 쓰고, A100에서 돌지 않던 연산만 같은 계산을 하는 다른 커널로 바꿨습니다. 자세한 차이는 클러스터 탭의 표를 보세요.

이용 시 주의

  • 대화는 서버에 저장되지 않고 이 브라우저 탭의 메모리에만 있습니다. 새로고침하면 사라집니다.
  • 기밀 정보나 개인정보는 입력하지 마세요. 요청은 해외 리전(영국·이탈리아·프랑스)의 GPU에서 처리됩니다.
  • 모델의 답변은 틀릴 수 있습니다. 날씨 도구는 실제 날씨가 아닌 데모용 가짜 데이터를 돌려줍니다.
  • A100에는 FP8 텐서코어가 없어 최신 GPU보다 느립니다. 동시에 많은 사람이 쓰면 대기열에서 기다릴 수 있습니다.
  • 저우선순위 VM을 쓰므로 Azure가 GPU를 회수하면 몇십 분간 쓸 수 없고, 그동안 자동으로 다시 시작합니다.

기능

  • 추론 모드: 답하기 전에 생각하는 과정(최대 16,384 토큰)을 펼쳐 볼 수 있습니다. 끄면 바로 답합니다(최대 8,192 토큰).
  • 도구 사용: 모델이 계산기, 현재 시각, (가짜) 날씨 도구를 호출하고, 도구는 이 브라우저에서 실행됩니다.
  • 문서 첨부: .txt·.md 파일을 합계 100만 자까지 붙일 수 있습니다. 모델의 최대 입력은 262,144 토큰입니다.
